# История изменений

[English](CHANGELOG.md) · **Русский**

Что менялось в каждом релизе, от новых к старым. Строка, которая начинается с **Известная
проблема**, говорит, где эта версия не работает, — она там потому, что кто-то запустил и не
заработало.

Текст каждого релиза на GitHub собирается из английской версии этого файла.

## 2026.10.23

- Telegram: в ежедневной сводке теперь есть результат `--check` — итоговая строка и пункты,
  которые требуют внимания. Если настройка «уехала», это видно на следующее утро.
- Релиз не публикуется, если CI не прошёл для его коммита или в этом файле нет записи о нём.
- CI: прогон на виртуальных машинах идёт через tmux там, где он есть в образе, — как и
  настоящий запуск.
- README: заметки для VPN-сервера.

## 2026.10.22

- Вся настройка теперь запускается в CI на виртуальной машине каждой поддерживаемой версии
  (Ubuntu 22.04, 24.04, 26.04, Debian 12, 13): чистый облачный образ, ответы на вопросы в
  терминале, проверка входа снаружи, перезагрузка, повторный запуск и новые команды.
- Исправлено: на Debian 12 настройка останавливалась на первом шаге (с версии 2026.10.15).
- Исправлено: на Ubuntu 26.04 настройка останавливалась на создании пользователя — там она
  не работала никогда.
- Новое: `--refresh` применяет настройки новой версии без вопросов; `--answers` печатает
  команду, которая повторяет настройку; `--undo` откатывает настройку из резервной копии.
- Начиная с этого релиза релизы неизменяемы.

## 2026.10.16

- Найдено чтением кода строка за строкой и исправлено: повторный запуск через `sudo harden`

**Известная проблема:** настройка откатывается на переключении SSH на облачных образах Ubuntu
24.04 (исправлено в 2026.10.18) и не завершается на Debian 12 и Ubuntu 26.04 (исправлено в 2026.10.22).
