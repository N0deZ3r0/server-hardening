# Code of Conduct

**English** · [Русский](#кодекс-поведения)

## The short version

Be decent. Assume the other person is acting in good faith. Criticise code and
measurements, not people.

## Not acceptable

- Personal attacks, insults, or demeaning comments
- Harassment of any kind, public or private
- Publishing someone else's private information without permission
- Sexualised language or imagery
- Sustained disruption of discussions

## Scope

Every space belonging to this project — issues, pull requests, discussions, commit
messages — and wherever you represent it.

## Enforcement

Report privately through a
[security advisory](https://github.com/N0deZ3r0/server-hardening/security/advisories/new),
which only the maintainer can read, or by contacting
[@N0deZ3r0](https://github.com/N0deZ3r0) on GitHub. Reports are handled confidentially;
the response ranges from a warning to a permanent ban.

# Кодекс поведения

[English](#code-of-conduct) · **Русский**

## Коротко

Ведите себя по-человечески. Считайте, что собеседник действует из добрых побуждений.
Критикуйте код и измерения, а не людей.

## Недопустимо

- Переход на личности, оскорбления, унизительные высказывания
- Травля в любом виде, публично или в личных сообщениях
- Публикация чужих личных данных без разрешения
- Сексуализированные высказывания и изображения
- Систематический срыв обсуждений

## Где действует

Во всех пространствах проекта — задачи, пул-реквесты, обсуждения, сообщения коммитов — и
везде, где вы его представляете.

## Как сообщить

Приватно — через
[security advisory](https://github.com/N0deZ3r0/server-hardening/security/advisories/new),
который видит только сопровождающий, или написав
[@N0deZ3r0](https://github.com/N0deZ3r0). Обращения разбираются конфиденциально;
реакция — от предупреждения до постоянной блокировки.
